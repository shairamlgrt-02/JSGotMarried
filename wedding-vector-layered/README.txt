WEDDING VECTOR EXPORTS

These SVGs contain vector paths only — no embedded PNG/photo. Each word and ornament is a separately named top-level group/layer (J&S seal, Jeger, ampersand, Shaira, flourish, date, handle, and hashtag groups). They are transparent and can be resized/recolored without pixelation.

The lettering is outlined so the supplied script is preserved exactly and will not be substituted by Illustrator. It can be edited as vector shapes (move, scale, recolor, adjust anchor points); changing the actual wording requires replacing that outlined text with live text in a matching font.

Use wedding-story-frame-* for the complete 1080×1920 composition, or welcome-mirror-lockup-* for the centered monogram + names + date without social handles/hashtags. Ivory and antique-gold colors are included.
